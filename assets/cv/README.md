# Che CHENG CV

This directory contains the LaTeX source for the English CV linked from the homepage.

## Build

Run:

```sh
make
```

The build produces:

```text
CV_Che_CHENG.pdf
```

## Maintenance

- Edit `cv.tex` for content updates.
- Run `make clean` to remove LaTeX auxiliary files.
- The previous Chinese PDF is preserved as `CV_CheCHENG_Zh.pdf`.
