About

I am an MPhil student in Computer and Information Engineering at The Chinese University of Hong Kong, Shenzhen, and a researcher at iHEAR Lab under the supervision of Prof. Fangxun Zhong. My work focuses on 3D vision, multimodal learning, and embodied intelligence, especially in settings where perception is incomplete, environments evolve over time, and decisions must remain reliable under uncertainty. I am particularly interested in safety-aware robotic perception and control, with an emphasis on multimodal perception, 3D scene understanding, and vision-language-action systems.

I build structured and verifiable multimodal systems that connect perception, reasoning, and action. My recent work spans visual-haptic interaction perception, physics-grounded VLA control, 3D structured spatial reasoning, GUI grounding, and LLM post-training. Across these projects, I care most about turning difficult problems into testable pipelines through structured modeling, clear failure analysis, and closed-loop evaluation. My primary toolkit includes PyTorch, PyTorch3D, OpenCV, Open3D, PEFT/LoRA, and modern VLM/LLM training pipelines.

I am actively seeking internship opportunities in VLA, VLM, multimodal foundation models, embodied AI, and reinforcement learning.

Selected Projects

Representative systems and research-oriented engineering projects across embodied AI, multimodal perception, LLM post-training, and 3D reasoning.

EmbodiedSceneAgent: 3D-Aware Vision-Language Planning for Long-Horizon Manipulation
A 3D-aware embodied agent for long-horizon manipulation, designed to improve task recovery under dynamic scene changes and partial observations.
Long-horizon embodied tasks often fail because scene state changes over time, observations are incomplete, and high-level plans cannot reliably recover from execution errors. This project studies how object-centric 3D scene memory can support planning, verification, and replanning in a closed loop. I built a modular pipeline with scene memory, planner, skill executor, verifier, and replanner, first bootstrapped with simulator teacher-state memory to stabilize high-level cognition, then used comparative evaluations to analyze the gap between teacher-state and predicted memory. The system is evaluated on CALVIN, RLBench, and VLABench to examine long-horizon success, subgoal completion, and recovery behavior.
VLA Embodied AI 3D Scene Memory Planning Verification Replanning
The code repository is being organized and will be available soon.
Cross-Website GUI Grounding with Verifiable Reward Optimization
A multimodal GUI grounding system that improves cross-website and cross-domain robustness through candidate generation and verifiable reranking.
GUI agents often break when grounding models overfit to specific layouts, websites, or interface styles, making it hard to transfer from seen environments to new ones. This project formulates GUI grounding as an instruction-conditioned perception problem from screenshot and instruction to target element, bounding box, click point, and action type. To address cross-website variation, I combined visual grounding with OCR and DOM-based candidate generation, then introduced verifiable reward signals such as element correctness, IoU, click validity, and action-type correctness to rerank candidates more reliably. The project focuses on making the perception layer more stable and more generalizable before moving to longer agent chains.
VLM GUI Agent OCR DOM Grounding Reward Reranking
The code repository is being organized and will be available soon.
Verifiable Code Generation Post-Training Pipeline for Open LLMs
An end-to-end post-training pipeline for code LLMs, covering supervised warm start, verifiable reward design, RL-style optimization, and execution-based evaluation.
Code generation quality is not just a language modeling problem: outputs also need to compile, satisfy tests, follow format constraints, and remain stable under evaluation. This project builds a full post-training pipeline around that challenge, from data preparation and SFT cold start to GRPO-based optimization and sandboxed execution. I designed verifiable rewards based on compile success, public test pass rate, and output validity, and used a unified execution-based protocol to compare Base, Structured Base, SFT, and SFT+GRPO settings. The goal is not only to improve benchmark scores, but to turn post-training into a reproducible engineering workflow with clear feedback signals and systematic error analysis.
LLM Post-Training SFT GRPO Reward Design Code Generation Evaluation
The code repository is being organized and will be available soon.
3D Structured Spatial Reasoning for Embodied Perception
A structured 3D perception module that bridges object-centric scene representation and relation-aware language grounding for embodied systems.
Embodied agents often struggle in relation-heavy scenes where language refers to anchors, spatial structure, and fine-grained object relations rather than isolated categories. This project addresses that gap by turning 3D grounding into a structured perception problem instead of a purely end-to-end matching task. I built a pipeline with object set construction, structured language parsing, soft anchor selection, relation scoring, and interpretable diagnostics, with a particular focus on hard cases such as same-class clutter, anchor confusion, and paraphrase variation. The resulting module is designed as a perception bridge that can provide downstream planners with more explicit and more diagnosable spatial reasoning signals.
3D Vision Spatial Reasoning Referring Expression Grounding Structured Parsing Embodied Perception
