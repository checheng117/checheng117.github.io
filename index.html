About

I am an MPhil student in Computer and Information Engineering at The Chinese University of Hong Kong, Shenzhen, advised by Prof. Fangxun Zhong at iHEAR Lab.

My research focuses on reliable multimodal perception for embodied AI, with an emphasis on structured 3D grounding, temporal interaction understanding, and geometry-aware reasoning. I am interested in how agents can use visual observations, task context, and spatial cues to form interpretable intermediate representations for decision-making in complex physical environments.

I use surgical scenes, RGB-D robot perception, and 3D visual grounding as challenging testbeds for studying reliability under occlusion, uncertainty, changing scene state, and limited supervision.

I am seeking PhD positions in embodied AI, robotic perception, multimodal learning, and reliable robot intelligence.

My technical toolkit includes PyTorch, PyTorch3D, OpenCV, Open3D, point-cloud processing, VLM/LLM fine-tuning, LoRA/PEFT, and reproducible evaluation pipelines.

Selected Open-Source Projects

Public repositories that reflect my current research-engineering interests in 3D grounding, RGB-D perception, embodied replanning, verifiable GUI grounding, and LLM post-training.

Spatial Prism: Relation-Aware 3D Grounding for Embodied Perception
Open Source
A diagnostic and controlled-ablation project for relation-aware 3D visual grounding. It builds scene-disjoint evaluation, hard-subset diagnostics, anchor-coverage analysis, and controlled relation-scoring ablations for embodied perception.
3D Grounding Relation Reasoning Embodied Perception Diagnostics
GitHub Report
RGB-D Spatial Grounding and Risk-Aware Robot Perception
Open Source
A real-time RGB-D perception pipeline for object-centric 3D grounding, instance segmentation, point-cloud back-projection, tracking, and nearest-distance risk estimation for embodied manipulation.
RGB-D Point Clouds Robot Perception Risk Estimation
GitHub
EmbodiedSceneAgent: Structured Scene Memory and Replanning for Embodied Tasks
Open Source
A closed-loop embodied cognition system built around observation, scene memory, planning, execution, verification, and replanning. The project emphasizes structured contracts, semantic acceptance filters, and failure-aware recovery under changing scene state.
Embodied Agents Scene Memory Replanning Verification
GitHub
OpenGUI-RL: Verifiable GUI Grounding for Computer-Use Agents
Open Source
A research-engineering project that formulates GUI grounding as a one-step contextual-bandit decision with candidate-aware supervision, deterministic reward signals, and reward-based reranking.
GUI Grounding Verifiable Reward Computer-Use Agents Reranking
GitHub
Verifiable Code Generation Post-Training for Open LLMs
Open Source
An auditable LLM post-training pipeline for code generation, covering supervised fine-tuning, execution-based evaluation, clean-view data construction, GRPO exploration, and reproducible run artifacts.
LLM Post-Training Code Generation SFT Evaluation
GitHub
